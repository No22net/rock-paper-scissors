
> Note: The final version provided includes **CSS and JavaScript inside the HTML file** for easy deployment and portability.

##  Getting Started

1. Save the provided HTML code as `index.html`.
2. Open the file in any modern web browser (Chrome, Firefox, Edge, Safari).
3. Start playing immediately – no installation or dependencies required.

##  Design Highlights

- Glass-morphism containers with backdrop blur.
- 3D button press effect (transform + box-shadow).
- Responsive layout – works on desktop, tablet, and mobile.
- Color-coded buttons for each move (warm earthy tones).
- Hover & active feedback for all interactive elements.

##  Customization Ideas

- Change the winning score (e.g., first to 5) by editing the `playerScore === 3` conditions inside `checkFinalWinner()`.
- Add sound effects for win/loss/draw events.
- Track game history (localStorage).
- Add a timer or animation for computer “thinking”.
